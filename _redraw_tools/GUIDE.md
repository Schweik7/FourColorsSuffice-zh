# 插图重绘统一规范（所有 agent 共用）

## 背景
这是《四色足矣：四色猜想是如何解决的》中译本的排版收尾工作。全书约 200 张几何类插图是从原书扫描截取的，线条发糊。任务是用 Python 程序化重绘为清晰的 SVG 矢量图，替换掉模糊的原图。**历史照片/人物肖像不在范围内，不要碰。**

## 技术栈
- Python + matplotlib（保存为 SVG：`fig.savefig(path, bbox_inches='tight', transparent=True)`）
- 需要曲线平滑时用 `scipy.interpolate.splprep/splev`
- 涉及真实地理边界（罕见，如美国/英国/欧洲地图）时用 `geopandas` + `shapely`，边界数据可从公开 GeoJSON 源下载（网络可用）
- **复用共享库**（就在本目录 `_redraw_tools/`，不要修改，只导入）：
  - `polyhedra.py`：通用凸多面体线画渲染器 `render_polyhedron(vertices, ax, view=..., ...)`。自动做背面剔除、画家算法排序、虚线隐藏边（以"X光透视"方式画在可见面之上，而非被遮挡）。
  - `solids.py`：15 种标准多面体的顶点生成函数（四面体、立方体、正八面体/十二面体/二十面体、棱柱、反棱柱、截半立方体、截角八面体、大斜方截半立方体、截角二十面体等），已用欧拉公式 V-E+F=2 验证顶点/面数全部正确。如果需要库里没有的多面体（如 C30 巴基球），自己在临时脚本里现算顶点坐标，不要改共享文件。

## 设计规范（样例阶段踩过的坑，务必遵守）

1. **用实色色块，不用文字颜色标签。** 原书受限于黑白印刷，很多插图里区域用斜体英文单词标注颜色（"red" "blue" ...）。我们重绘时应直接用真实色块填充对应区域，不再写文字。标准色号：
   `red=#c0504d  green=#5a9257  yellow=#e0b23c  blue=#4f7cac`
   注意：**只有"颜色名词"才替换成色块**；如果标注的是变量名（国家 A/B/C、区域 P、顶点 α/β/γ 等），仍然保留斜体文字标签，不要瞎替换。

2. **多边形顶点要延伸出"胡须线"。** 书中凡是画孤立的 n 边形示意图（二边形、三角形、正方形、五边形等，代表地图里一个 n 次交汇点/n 条边界线区域），每个顶点都要向外延伸一小段线，表示该顶点是多条边界线的交汇点、地图在图外还有延续。参考已完成的 fig-070（三角形）。

3. **多面体选读者最容易辨认的经典朝向。** 例如四面体/棱锥要顶点朝上、底面水平（用 `solids.tetrahedron_upright()`），立方体正面朝向观者，不要用会让读者困惑的斜怪角度。

4. **抽象拟人化"国家"地图用平滑样条曲线，不要用直线折线。** 参考 `smooth_closed` / `smooth_open`（用 `splprep(..., per=True)` 画封闭轮廓，`per=False` 画开放曲线段）营造手绘感的圆润轮廓。

5. **【最重要】先读懂上下文再画，涉及逻辑推理链条的图组必须保持拓扑一致。** 本书很多插图不是孤立装饰画，而是承载具体推理过程的连续画面（比如某张地图在文字论证中被反复重新着色、某个构型在放电过程中电荷反复转移）。这类图之间的区域邻接关系、顶点标记、颜色状态**必须与正文描述的推理过程完全对应**，不能自由发挥形状。你收到的每个"工作单元"（unit）内的所有图，都被判定为可能属于同一逻辑场景，已经把对应的完整正文段落给你了——动笔前请完整读一遍，搞清楚这组图是"同一对象的连续演化"还是"同类但互相独立的个体"，再决定要不要在多张图间共享同一套底图/坐标。

## 输出要求

- 每张图输出为 SVG，保存到项目 `images/` 目录下，**文件名沿用原文件名（把扩展名从 .jpg 改成 .svg，其余不变）**，例如 `fig-048_正四面体.jpg` → `fig-048_正四面体.svg`。
- 背景透明（`transparent=True`），不要加边框或标题文字（图注文字由正文 Markdown 负责，不要画进图里）。
- **不要删除或覆盖 `images/` 目录下的原始 .jpg 文件**（它们保留作对比留档，且 `images_original/` 已经整体备份过一次）。
- **不要修改 `FourColors_Suffice_zh.md`**（引用路径由主进程最后统一批量替换，避免多个 agent 同时改同一个文件冲突）。
- **不要修改 `_redraw_tools/polyhedra.py` 或 `solids.py`**（共享只读库；如需新函数写在自己的脚本里）。
- 完成后用几句话总结：画了哪些图、遇到需要读懂上下文才能确定的内容判断是什么、有没有拿不准的地方。
